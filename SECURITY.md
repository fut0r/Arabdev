# Security policy

## Reporting a vulnerability

Please report security problems privately to **support@arabdev.site**, not in a public issue.

Include what you found, the steps to reproduce it, and what an attacker could do with it. Please don't
access other people's data, degrade the service or run automated scanners against arabdev.site while
testing; a local copy (see the README) is the place for that.

We'll confirm we received your report, keep you updated while we fix it, and credit you in the
[patch notes](https://patch.arabdev.site) if you'd like.

## Supported versions

Only the version running at [arabdev.site](https://arabdev.site), built from the `main` branch, gets
security fixes.
